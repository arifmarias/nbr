# TaxSight AI: NBR pitch pack

Open `taxsight/index.html` in a browser (no server or internet needed).

- `taxsight/deck.html`: 14-slide presentation. Arrows to navigate, `T` theme, `F` fullscreen, `P` print to PDF.
- `taxsight/demo.html`: interactive MVP on a synthetic Tax Zone 10 (about 4,100 buildings). Start with the guided demo.
- `taxsight/assets/`: shared code, GSAP, and self-hosted Space Grotesk, IBM Plex Sans and Noto Sans Bengali fonts.

All names, buildings and figures are synthetic. Pilot economics follow the illustrative assumptions in the proposal.
